# TTTS

Бесплатная программа для Windows: читает чат вашего канала на Twitch и озвучивает сообщения
голосами [Fish Audio](https://fish.audio). Озвучка по префиксу (например `!tts`) или за награду
с вводом текста, очередь с пропуском и паузой, фильтры и антиспам, мьюты, вывод звука в OBS.

## Установка

1. Откройте [последний релиз](https://github.com/Heimkrieger/TTTS/releases/latest) и скачайте
   архив `TwitchTTS-<версия>-win-x64.zip`.
2. Распакуйте в обычную папку, например на рабочий стол или в `D:\Программы\TTTS`. Не в
   `Program Files`: программа хранит настройки рядом с собой, в папке `data`.
3. Запустите `TwitchTTS.exe`.

Windows может показать окно "Windows защитила ваш компьютер": у программы пока нет платной
цифровой подписи. Нажмите "Подробнее", затем "Выполнить в любом случае". Проверить архив можно
на [VirusTotal](https://www.virustotal.com); контрольная сумма лежит в релизе рядом с архивом
(файл `.sha256`).

При первом запуске мастер попросит канал и ключ Fish Audio.

### Как получить бесплатный ключ Fish Audio

1. Откройте https://fish.audio/app/api-keys/
2. Нажмите "Вход / Регистрация" справа вверху. Войти можно через Google, GitHub, Apple или по
   почте. Карта не нужна.
3. Нажмите "Создать ключ API". Название ключа любое, например TTS.
4. Сразу скопируйте ключ: Fish показывает его один раз. Не успели - удалите ключ на сайте и
   создайте новый.
5. Вставьте ключ в программу (мастер первого запуска или раздел "Подключение") и нажмите
   "Сохранить ключ".

Бесплатно работает модель s2.1-pro-free, в программе она стоит сразу. Платные модели без
пополнения баланса на fish.audio не работают.

## Обновления

При запуске программа проверяет, не вышла ли новая версия. Если вышла, предложит обновиться
одной кнопкой. Настройки и ключ сохраняются. Каждый архив подписан ключом автора: программа
не поставит архив с неверной подписью.

## Куда программа ходит в сеть

- **Twitch:** читает чат анонимно, без входа в ваш аккаунт.
- **Fish Audio:** отправляет текст сообщений на озвучку с вашим ключом.
- **7TV, BTTV, FFZ:** списки эмоутов канала, чтобы не читать их вслух.
- **GitHub:** проверка обновлений.

Никакой статистики и сбора данных нет. Ключ Fish хранится только на вашем компьютере,
зашифрованным средствами Windows.

## Для разработчиков

Electron + React + TypeScript. Нужен Node.js 24.

```
npm install
npm run dev        # запуск из исходников
npm test           # тесты
npm run lint       # проверка кода
npm run release:zip  # сборка архива в release/
```

Выпуск версии: описать изменения в `CHANGELOG.md`, `npm version X.Y.Z`, отправить ветку и метку.
GitHub Actions соберёт архив, подпишет его и выложит релиз.
